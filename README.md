# Zhsunyco-213-4-BLE
Reverse-engineering notes for Zhsunyco 213-4-BLE electronic shelf labels (ESL), sold under the WoLink / WoPda brand and also as generic "2.13-inch BWRY BLE price tag" on marketplaces.  Everything below was recovered by decompiling the vendor's Flutter app, proxying its HTTPS traffic, and probing a live tag.
